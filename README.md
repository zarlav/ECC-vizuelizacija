# ECC-vizuelizacija
Implementacija edukativnog grafickog interfejsa za vizuelizaciju procesa kodiranja, pojavu i korekciju gresaka.
------------------------------------------------------------------------------------------------------------------
**NAPOMENA**
Pre pokretanja aplikacije potrebno je **preuzeti** biblioteku sa sledeceg linka : https://github.com/raysan5/raylib/releases/download/6.0/raylib-6.0_win64_msvc16.zip
U project properties pritisnuti na C/C++, zatim promeniti Additional Include Directories na ....raylib\raylib-6.0_win64_msvc16\include, kao sto je prikazano na slici.
